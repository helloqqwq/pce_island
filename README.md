## 介绍

PCE-Island 是一款 Windows 桌面增强应用，将系统信息、工具、游戏和辅助功能集成到一个悬浮的灵动岛界面中。采用全屏透明置顶窗口设计，配合自研液态玻璃渲染引擎，实现实时折射、磨砂和光照效果。

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 (x64) |
| 架构 | x64 |
| 磁盘空间 | 约 300MB |
| 权限 | 管理员权限（安装时） |

## 下载与安装

1. 前往 [Releases](../../releases) 页面
2. 下载最新版安装包 `pce-island-Setup-x.x.x.exe`
3. 以管理员权限运行安装程序
4. 安装完成后自动启动

> 也可以下载免安装版 `pce-island-x.x.x-portable.zip`，解压后直接运行 `pce-island.exe`

## 液态玻璃效果

自研渲染引擎，核心特性：

| 特性 | 说明 |
|------|------|
| Snell 壳层折射 | 折射率可调（默认 1.52），模拟真实光线弯折 |
| 液态波动 | 可调波动参数与渲染帧率 |
| 3 层预模糊 | 防止灰雾边 |
| 径向磨砂 | 中心磨砂 + 磨砂过渡带 |
| 高光描边 | 边缘光照效果 |
| SDF 缓存 | Signed Distance Field 优化性能 |
| 多形状支持 | 圆形 / 胶囊 / 圆角矩形（收起自动胶囊，展开圆角矩形） |
| WDA 排除捕获 | 排除自身窗口的屏幕捕获，防止递归 |
| 鼠标光照 | 跟随鼠标位置的光照效果 |

### 玻璃可调参数

- 折射率
- 中心磨砂强度
- 磨砂过渡带宽度
- 液态波动开关
- 刷新率
- 液态渲染帧率
- 折射模式
- 圆角半径
- 按钮磨砂

## 无障碍功能

### 色盲校正（系统级）

- 支持 7 种色盲类型：红色盲、绿色盲、蓝色盲、红色弱、绿色弱、全色盲、正常
- Daltonize 算法（将无法区分的颜色差异转移到可感知通道）
- 基于 Windows Magnification API，全系统所有应用生效
- 退出应用时自动重置
- 内置石原氏色盲测试图

### 眼动控制

- 眼动追踪 + 眨眼检测（MediaPipe + OpenCV）
- 注视移动光标
- 左眼眨眼 = 左键点击
- 右眼眨眼 = 右键点击
- 双眼连眨两次 = 虚拟键盘
- 注视按键 1 秒自动输入
- 中文拼音输入（空格选词）
- 16 点校准流程
- 实时状态显示

### 视觉辅助

- OCR 文字识别（鼠标区域 / 全屏扫描）
- 语音朗读（讯飞 TTS，小燕女声 / 小峰男声）
- 按键朗读、字符朗读
- 鼠标指示跟随
- 可配置：OCR 半径、语速、音量、发音人
- 快捷键支持

## 技术架构

| 层 | 技术 |
|----|------|
| 前端 | Electron 33 + HTML5 + CSS3 + JavaScript |
| 玻璃引擎 | 自研 Snell 折射 + SDF + Canvas |
| Python 后端 | Python 3.11 + Nuitka/PyInstaller 打包 |
| C++ 后端 | WinRT/SMTC + WebSocket |
| AI 引擎 | OpenSwarm（蜂群协作 + 代理模式） |
| 无障碍 | MediaPipe + OpenCV + Windows Magnification API |
| 原生调用 | koffi（user32.dll / shell32.dll / ole32.dll） |

### 窗口架构

- 全屏无边框透明置顶窗口
- 跳过任务栏
- 鼠标穿透智能检测（交互区捕获 / 非交互区穿透）
- WDA_EXCLUDEFROMCAPTURE（从屏幕捕获中排除自身）
- 系统托盘图标（显示/隐藏/退出）
- 光标位置轮询（32ms 间隔）

### 启动流程

1. 初始化文件结构
2. 创建窗口 + WDA 排除
3. 创建系统托盘
4. 启动 Python 后端
5. 启动剪贴板监控
6. 启动 OpenSwarm AI
7. 启动音乐服务
8. 启动色盲校正（如有已保存设置）

### 关闭流程

依次安全停止所有后端进程。
